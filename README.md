# dotlife wallpapers

The full-size wallpaper photos of the «نقطه» (dotlife) app, mirrored here so the app can download them
through jsDelivr on networks where the original hosts do not load. Images only, cropped to a phone's
shape (1170×2340); no code. The app pins a tagged version:
`https://cdn.jsdelivr.net/gh/mostafauxd-cmyk/dotlife-wallpapers@<tag>/full/<id>.jpg`
(`1.0.0` holds the earlier set).

Each photo stays under its own licence; credit goes to its author.
